## Возможные причины

- Недостаточно памяти для выполнения операции
- Ошибка сети при обращении к OpenRouter API
- Превышен timeout запроса
- Неверная конфигурация системы
- Поврежденные зависимости

## Немедленные действия

1. Перезапустите mcp-validator
2. Проверьте доступность сети
3. Убедитесь в корректности OPENROUTER_API_KEY
4. Проверьте доступное место на диске
5. Проверьте логи с уровнем DEBUG

## Если ошибка повторяется

1. Обновите Node.js до версии 20+
2. Переустановите зависимости: `yarn install`
3. Очистите кеш: `yarn cache clean`
4. Проверьте системные ресурсы
