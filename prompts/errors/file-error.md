## Возможные причины

- Файл не существует или недоступен
- Недостаточно прав для чтения/записи
- Файл используется другим процессом
- Неправильный путь к файлу
- Превышен лимит размера файла ({{file_size_limit}})

## Рекомендации

1. Проверьте существование файла
2. Убедитесь в корректности пути
3. Проверьте права доступа к файлу
4. Убедитесь, что файл не заблокирован
5. Проверьте размер файла (максимум {{file_size_limit}})

## Безопасность

Доступ разрешен только к файлам в рабочей директории.
Запрещены операции с системными файлами.
